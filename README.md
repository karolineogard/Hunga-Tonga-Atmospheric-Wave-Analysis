# Hunga Tonga Infrasound Analysis

MATLAB project analysing global infrasound recordings from the 15 January 2022
Hunga Tonga–Hunga Ha'apai volcanic eruption.

The analysis uses recordings from 201 stations to study the propagation of the
atmospheric pressure wave generated by the eruption. The project includes
station-distance calculations, FIR filtering, custom signal-processing
implementations, section plots, manual arrival-time picking, and propagation
celerity estimation.

## Highlights

- Analysed recordings from 201 global sensor stations
- Computed great-circle distances from Hunga Tonga to each station
- Created an azimuthal equidistant station map centred on the volcano
- Implemented discrete-time convolution from its mathematical definition
- Implemented and verified a custom DTFT routine against MATLAB's `freqz`
- Classified FIR filters as lowpass, bandpass, and highpass
- Filtered all station recordings and created distance-versus-time section plots
- Picked first-arrival times and estimated the infrasound propagation celerity

## Key result

Using manually picked first-arrival times and a linear distance–travel-time
fit, the estimated propagation celerity was:

```text
310.5 m/s
```

This is consistent with the fast Lamb-wave / thermospheric-duct arrival
identified in the recordings.

## Methods

### Station geometry

Great-circle distances between Hunga Tonga and each station were computed
using the haversine formula. Station locations were visualised with an
azimuthal equidistant projection centred on the volcano.

### Signal processing

Three provided FIR filters were investigated by plotting their impulse
responses and magnitude spectra. I implemented:

- Custom discrete-time convolution
- Custom discrete-time Fourier transform (DTFT)
- FIR filtering of all station recordings

The custom DTFT implementation was validated against MATLAB's built-in
`freqz` function.

### Arrival-time picking and celerity estimation

Arrival times were manually selected as the first clear onset on the
highpass-filtered traces. A linear model was fitted between source-to-station
distance and travel time:

```

D = ct + b
```

where $D$ is the distance, $t$ is travel time, $c$ is propagation celerity,
and $b$ is an intercept term.

## Running the project

### Requirements

- MATLAB
- The project dataset / station recordings

1. Clone the repository:

```bash
git clone https://github.com/karolineogard/hunga-tonga.git
cd hunga-tonga
```

2. Open MATLAB in the project folder.

3. Run the main script:

```matlab
main
```

Replace `main` with the name of the script that reproduces your analysis.

## Background

The Hunga Tonga–Hunga Ha'apai eruption generated atmospheric waves detected at
stations worldwide. This project focuses on extracting and analysing these
arrivals using filtering, time–distance visualisation, and linear celerity
estimation.
